# Follow-up com Cliente (MG2)

Resumo: Follow-up de aprovações e entregáveis pendentes com o cliente — contato no grupo ou e-mail.

Papéis: CS, GP

Estimativa: 0.5h (semanal)

Cadência: weekly

Checklist:
- Verificar aprovações pendentes
- Atualizar cliente sobre bloqueios
- Agendar próxima call se necessário

Descrição longa:
Follow-ups regulares reduzem atrasos e melhoram SLAs. Registrar interações no grupo do cliente (regra: nunca enviar mensagens privadas para assuntos de crise).
