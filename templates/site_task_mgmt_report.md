# Extração e Publicação de Relatório (MG3)

Resumo: Extrair dados, gerar e publicar relatório mensal/pulse no repositório do cliente.

Papéis: AD, CS

Estimativa: 1h (mensal)

Cadência: monthly

Checklist:
- Executar extração de dados
- Gerar arquivo do relatório
- Publicar na pasta do cliente
- Notificar grupo do cliente

Descrição longa:
Processo operacional para criar e publicar o relatório mensal/pulse. Deve haver template de relatório e local padrão de publicação.
